## Fixed system

- Canvas: vertical 3:5 unless the user requests otherwise.
- Surface: full-frame warm paper with fibers, fine grain, dust, scan noise, slight aging, matte absorbency; no border, no mockup.
- Attention geometry: 70–90% of the canvas reads as open paper; one main visual cluster occupies ~8–25%.
- Visual event: one primary metaphor or relation — never a full illustrated scene or an inventory of objects.
- Depth: flat orthographic scan, diffuse light, low-to-medium contrast; no hard shadow, no mockup depth.
- Typography: sparse typewriter, old serif, fine serif, monospaced, or restrained small sans; text behaves like a note, fragment, label, date, or private sentence, never an advertising headline.
- Reproduction: focal element and typography belong to the same printed/scanned world via halftone, xerox softness, risograph grain, letterpress bleed, scanline, paper edge, or slight misregistration.
- Mood: quiet, poetic, distant, archival, diary-like, memory-like, Japanese/Korean indie zine.

## Photo contract (the supplied photo is the edit target)

Use the supplied photo with **High preservation**: identity, facial structure, body proportions, pose when relevant, defining markings, product geometry, object count, silhouette, and recognizable colors must stay recognizable — prefer an original-photo crop, clipping, or printed fragment over redrawing the subject; never convert an identifiable person, pet, product, or artwork into a silhouette or loose illustration. Allow changes only to crop, scale, palette, surface treatment, and surrounding composition. State in the prompt what must remain recognizable, what may change, and what new poster elements may be introduced. The photo fragment typically becomes the faded-photo or clean-crop focal element.

## Metaphor

One object, fragment, photo crop, specimen, silhouette, printed illustration, texture window, typographic object, or small conceptual relation carries the meaning. Derive the subject from the content before choosing its material form; the metaphor must explain why this subject represents the content. For abstract themes prefer a small relation: two fragments nearly touching, one interrupted line, a window cut from a solid block, a repeated form with one missing part, two panels showing different states, an object isolated from its expected context. Keep the event isolated and imageable — do not expand it into a full scene.

## Color

One main high-chroma hue: cobalt, ultramarine, cyan, violet, magenta-pink, lemon yellow, pear green, orange, or tomato red — choose by the content, not habit. The main color occupies ~0.8–2.5% of the canvas or 15–35% of the visual cluster, carried by the subject, cutout, block, partial photo region, or bold fragmented type — not automatically reduced to a tiny registration dot. Paper, grayscale photo, microtext, and secondary marks stay subdued. A secondary hue is optional and ≤10% of the total chromatic area. Never weaken the main color with pale/muted/faded/pastel/low-saturation wording.

## Variation axes (pick one per axis, don't default to centered)

Layout family: center-fragment / lower-left-float / upper-right-block / dual-panel / irregular-cutout / type-led / dot-orbit / single-specimen / diagonal-notes / edge-counterweight. Focal-element form: tiny faded photo / clean rectangular crop / torn-paper clipping / flat silhouette / opaque printed color block / old printed illustration / object specimen / translucent geometric overlay / abstract texture window / fragmented type as image. Typography mode: fragmented floating letters / short phrase pressed against the image edge / archive microtext with date or weather / diagonal scattered words / low-contrast gray ghost text / headline-as-object with rough letterpress / text inside a color block or cutout / almost textless with one tiny caption. Texture mode: xerox softness / risograph grain / letterpress ink bleed / halftone degradation / film-grain photograph / scan noise and paper fibers / aged paper mottling / slight misregistration. Decorative marks: zero to three restrained elements (dot group + fine annotation line, tiny arrow + dashed line, transparent rectangle + registration mark, one curved hand-drawn line, small color block + date-like label, or none) — never the subject.

## Compiler shape and rules

Four compact paragraphs: 1) canvas + paper + negative-space share + cluster size and position; 2) photo preservation contract + visual metaphor + focal-element form + material treatment; 3) typography + exact main hue + chromatic material form and share + print defects; 4) flat scan mood + relevant avoids. Name the concrete focal-element carrier and color carrier — no ambiguous shorthand like "somewhere", "artistic", "balanced". Supplied poster text is used verbatim; otherwise invent one short phrase. Low contrast applies only to paper, photograph, and secondary ink — never the accent. If the theme is not maritime, no ship-mooring objects, nautical emblems, or generic pictograms.

## Anti-identity

No full-bleed scene, commercial headline hierarchy, product ad, logo, CTA, brand campaign, glossy mockup, clean UI white, cinematic lighting, hard shadow, depth of field, 3D, neon, cyberpunk, cute cartoon, anime, fashion-editorial drama, dense scrapbook, too many objects, multicolor palette, stock-photo realism, long clean text block. Do not copy source text, brands, signatures, watermarks, exact dates/locations, or exact compositions. The result must remain a sparse vertical paper poster with one clear visual event — not a commercial ad or generic collage template.
