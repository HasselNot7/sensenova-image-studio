把照片变成一张独立成立的纸面海报。照片只是语义证据与刺激源，绝不是最终画面里的图层；不是滤镜、风格迁移、描摹或插画式复制。

先定三件事：语义内核（让画面成立的最小主体／关系／事件，只留 2–4 个来源锚点，默认不保留原构图）；一句话命题（观众应感到或重新注意到什么，必须来自这张照片，不许用安静、治愈、怀旧这类空标签）；一个主要张力（亲密／距离、庇护／囚禁、动／静、渺小／辽阔、记忆／消失之类），用尺度、间隔、方向、遮挡、包围、中断、温度、明度或材质表达，绝不写成解释性文字。隐喻只变换一个源自画面的对象、关系或材料行为，一个即可。

构图：竖图 3:5、横图 5:3、方形或暧昧时 3:5；68–85% 是安静纸面，一个 12–32% 的主体簇；一个主导体量 + 1–3 个支持形 + 一个克制的纹理场，按视觉重量而非面积配平。家族选一：非对称孤岛／撕纸窗口／方向漂移／节奏循环／错叠碎片／垂直张力／辅助星座。图底清晰、非对称平衡、视线有入口—相遇—移动—安静出口，绝不习惯性居中或把画面均分。

语法：编辑式抽象——保留内核、主导手势与一个空间线索，删去约 65–90% 的描述性细节，换成简化块面、断裂轮廓、纸片、稀疏标记与印刷场；主语法 1 + 辅助 ≤1（剪纸块面／干印剪影／断裂轮廓／节奏场／碎片堆叠／轨道漂移）。默认弱化面孔，除非要求相似。

边缘：一种主处理 + 至多一种次要，绝不全用——纤维撕纸边；2–3 条窄而不规则的灰阶边（无投影）；点状消融；1–3 个来源派生的不规则标记边；干净轮廓直接接纸。可让 0–2 个形跨越边界，保持平扫深度。

色彩：克制的纸与墨，加一个明确的高饱和主色（点名色相：钴蓝、群青、梨绿、番茄红、柠檬黄、品红、橙），按视觉角色（焦点钉、配重、桥、场、线索）与来源关系选择，占画面 0.8–3% 或主体簇 10–30%，最多 2 个小回声（<25% 主色面积）；绝不用 pale/muted/faded 削弱它。默认不选蓝。仅当主题出现精确触发词 `单色块模式` 时：只用自然纸色 + 一套中性墨系 + 一个 3–12% 画面的实心饱和色块作视觉入口，无回声无点缀。

文字：完全自由的作者材料，任何语言、片段、重复或无字皆可，可tiny、超大、裁切、散落、旋转、遮挡、碎片化；唯一规则是加深命题、张力、隐喻或留白，不做 neatly caption。
